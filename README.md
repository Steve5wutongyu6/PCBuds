# PCBuds

把 F5 变成耳机降噪模式切换的菜单栏后台小工具。

## 支持的耳机

- OPPO Enco Air5 Pro
- OPPO Enco Free4
- realme Buds T500 Pro 系列

## 安装

1. 下载 `PCBuds-app.zip`,解压得到 `PCBuds.app`。
2. 把 `PCBuds.app` 拖进「应用程序」。
3. 打开 PCBuds。首次打开可能需要在「系统设置 › 隐私与安全性」中点「仍要打开」。

## 首次运行需要的权限

在「系统设置 › 隐私与安全性」中打开对应的开关:

- **辅助功能**:用来拦下 F5 按键。
- **蓝牙**:用来连接耳机。第一次切换时会弹出系统询问,允许即可。

授权后 PCBuds 会自动检测到,窗口自行关闭。

## 使用

按 **F5** 循环切换:

> 降噪 → 通透 → 关闭 → 降噪 …


## 退出

在「活动监视器」里结束 `PCBuds` 进程。
