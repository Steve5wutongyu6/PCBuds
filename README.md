# PCBuds

把 F5 变成耳机降噪模式切换的菜单栏后台小工具。没有主窗口,常驻菜单栏。

## 支持的耳机

- OPPO Enco Air5 Pro
- OPPO Enco Free4
- realme Buds T500 Pro 系列

## 安装

1. 下载 `PCBuds-app.zip`(GitHub Actions 的构建产物),解压得到 `PCBuds.app`。
2. 把 `PCBuds.app` 拖进「应用程序」。
3. 打开 PCBuds。构建产物未签名,首次打开可能需要在「系统设置 › 隐私与安全性」中点「仍要打开」。

## 首次运行需要的权限

在「系统设置 › 隐私与安全性」中打开对应的开关:

- **辅助功能**:用来拦下 F5 按键。不开时 F5 没有效果。
- **蓝牙**:用来连接耳机。第一次切换时会弹出系统询问,允许即可。

授权后回到 PCBuds,在菜单栏图标里重新检测权限。

## 使用

按 **F5** 循环切换:

> 降噪 → 通透 → 关闭 → 降噪 …

耳机未连接时按键不起作用,也不会有任何提示。

## 退出

点菜单栏图标 → **退出**。

卸载:退出后把 `PCBuds.app` 拖进废纸篓即可。
